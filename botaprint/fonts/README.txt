Place font files here.

Required bold font (supports Cyrillic, Kazakh, tenge sign):
  DejaVuSans-Bold.ttf

Download: https://dejavu-fonts.github.io/

If this file is absent, BotaPrint falls back to Windows system fonts
in this priority order:
  C:\Windows\Fonts\segoeuib.ttf   (Segoe UI Bold)
  C:\Windows\Fonts\arialbd.ttf    (Arial Bold)

For PyInstaller packaging, place DejaVuSans-Bold.ttf here so it is
bundled into BotaPrint.exe automatically.
