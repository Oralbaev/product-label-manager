Place TrueType font files here to override the system fonts used in PDF labels.

Expected filenames:
  DejaVuSans.ttf       — regular weight
  DejaVuSans-Bold.ttf  — bold weight

Download from: https://dejavu-fonts.github.io/

If these files are absent, the app falls back to Windows system fonts in this order:
  Regular : segoeui.ttf  →  arial.ttf
  Bold    : segoeuib.ttf  →  arialbd.ttf

Both Segoe UI and Arial on Windows 10 support Cyrillic, Kazakh letters, and the ₸ sign.
